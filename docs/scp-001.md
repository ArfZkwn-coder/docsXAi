# SCP-001

:::info Fiction
This page is about the **SCP Foundation**, a collaborative fiction project. Everything described here is invented.
:::

## What is SCP-001?

The SCP Foundation is a wiki where writers create in-universe case files about anomalous objects, creatures and events. Each file has a number, and the fictional Foundation's job is to secure, contain and protect.

**SCP-001 is the one number with no single answer.** Rather than one article, the SCP-001 page is styled as a classified index of competing **proposals**. Each is a complete, self-contained answer to the question "what is the Foundation's most important secret?", written by a different author.

The page explains this inside the story: a general notice warns that decoy SCP-001 files were created to hide the real one, and that there may be several decoys, or none. Readers never learn which file is genuine, so each proposal stands on its own.

The index lists dozens of proposals across the wiki's series, each under a code name. A few examples:

| Code name | Proposal |
| --- | --- |
| Dr. Clef | The Gate Guardian |
| Dr. Gears | The Prototype |
| Jonathan Ball | Sheaf of Papers |
| qntm | The Lock |
| S. Andrew Swann | The Database |
| djkaktus/TwistedGears | Ouroboros |

## The Gate Guardian

Dr. Clef's proposal is one of the best known. In it, SCP-001 is:

- **A colossal winged figure.** A humanoid about 700 cubits tall stands with its head bowed, holding a flaming sword point-down in both hands. The sword is catalogued separately as SCP-001-2, and the number of wings varies between sightings, from 2 to 108.
- **Classed Euclid/Keter.** The Foundation can watch it, but has no hope of controlling it.
- **Near the Tigris and Euphrates.** It stands at an undisclosed site and is observed around the clock from a hidden post, Site 0, at least 10 km away.
- **Untouchable.** Anything within 1 km of it is destroyed, and attacks on it have been answered at any range.
- **A messenger.** People who see it hear a voice give them a one-word command, usually **FORGET**. The proposal links the Foundation's origin to the one person who was told **PREPARE**.

The figure appears to stand guard at a gate opening onto a grove. Together with the rivers and the flaming sword, this echoes the guardian placed at the gate of Eden in Genesis.
